# OpenAPI Integration with React

This project demonstrates how to integrate OpenAPI-generated client code into a React application. The API client is generated using the `openapi-generator-cli` tool, and the React components use this client to interact with the API. The goal is to streamline the process of making API calls from the React frontend to the backend.

## Getting Started

To get a copy of this project running locally, follow these instructions.

### Prerequisites

Ensure you have the following installed on your machine:

- **Node.js**: Required to run the React app and manage dependencies. [Download Node.js](https://nodejs.org/).
- **npm** or **yarn**: A package manager to manage dependencies.
- **Git**: Version control system to clone the repository.

### Installation

Follow these steps to install and set up the project:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/AliRazaSaqib/open-api-generator-code-setup.git
   cd open-api-generator-code-setup
   ```

2. **Generate end points**:

```npm run generate:api

```
